# Projeto Java
## LeiloesTDSat

### Explicação

Este projeto foi desenvolvido utilizando a linguagem Java.
O sistema permite realizar o cadastro e a listagem de produtos utilizando uma estrutura ArrayList para armazenar os dados durante a execução do programa.

O projeto não utiliza banco de dados, sendo os dados armazenados temporariamente em memória através de uma lista de objetos.
